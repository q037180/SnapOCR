# SnapOCR — 本地离线截图 OCR

按一个热键，框选屏幕任意区域，文字自动识别并复制到剪贴板。**全程本地运行，不上传任何数据。**

![SnapOCR 演示：热键框选 → 识别 → 自动复制](assets/demo.gif)

## 特性

- 截图 → OCR → 复制剪贴板，一步完成（默认热键 `Ctrl+Alt+Q`）
- **多语言识别**（参考 PaddleOCR 多语言模型）：设置里切换简中 / 繁中 / 英 / 日 / 韩，**5 种基础模型已内置，离线即用**
- **图像增强**（参考 EasyOCR / Umi-OCR 预处理）：深色主题截图自动反色、低对比度文本 CLAHE 增强，深色 IDE / 夜间模式识别率显著提升
- **表格识别导出 Excel**（参考 PaddleOCR PP-Structure）：「识别表格」框选表格区域 → 生成行列矩阵 → 保存 xlsx（内容同时复制到剪贴板）
- **水印关键词过滤**（参考 Umi-OCR 忽略区域）：设置中配置关键词，命中的文字行自动剔除
- **GPU 加速**（参考 EasyOCR）：自动检测 CUDA / DirectML，无 GPU 时安静回退 CPU
- **段落合并**（参考 Umi-OCR 段落还原）：多行文本自动合并为自然段，适合文章 / 文档截图
- **二维码识别**（参考 Umi-OCR）：框选区域没有文字时自动兜底解码二维码
- **PDF 整档识别**（参考 Umi-OCR / OCRmyPDF）：点「PDF识别」或直接把 PDF 拖进主窗口，逐页渲染识别（≈144dpi），多页结果按「== 第 N 页 ==」分组，带进度条可取消
- **截图贴图**（参考 Umi-OCR 贴图）：点「截图贴图」框选后钉在桌面置顶显示，可同时钉多张；拖动移动、滚轮缩放（Ctrl+滚轮调透明度）、双击或右键关闭
- **文件夹批量识别**：把整个文件夹拖进主窗口，自动递归收集其中所有图片（上限 500 张）批量识别
- **拖拽批量识别**：把图片文件（png/jpg/bmp/webp 等）拖进主窗口即可批量识别
- **截屏翻译**（默认热键 `Ctrl+Alt+T`）：框选 → 识别 → 自动弹出翻译窗口并翻译，原文可编辑重译
- **长截图**（默认热键 `Ctrl+Alt+L`）：框选区域后自动滚动拼接，整页可保存/复制图片，或直接「识别并复制」「识别并翻译」
- **翻译窗口**：粘贴/输入文本即时翻译，支持 11 种语言互译（免费接口，无需 API Key）
- **导出 txt/docx/pdf/md**：历史记录或译文可一键导出为文本、Word、PDF 或 Markdown 文件
- **自定义快捷键**：主窗口「设置」或托盘菜单 →「快捷键设置」按键录制，自动保存并即时生效
- 基于 RapidOCR（PP-OCRv6 模型 / ONNXRuntime），中文识别效果好，**完全离线**
- 检测输入自适应压缩：1080p 全屏识别约 7 秒（低功耗 CPU 实测），框选小区域不受影响
- 智能按行还原排版，多栏文本不乱序
- 中文智能排版：自动去除中文字符间多余空格（托盘菜单可开关）
- 内置历史记录，支持关键词搜索，随时回溯、再次复制；单击/双击条目浮窗预览完整内容
- 识别完成托盘气泡提示，支持最小化到托盘常驻
- 模型随包内置，首次使用无需联网下载

## 环境要求

- Windows 10/11（完整支持）；Linux / macOS 大部分功能可用（见下方跨平台说明）
- Python 3.9+

## 跨平台兼容性（Linux / macOS）

核心功能（截图识别、翻译、历史、PDF 整档识别、表格识别、贴图、批量导入、各格式导出）均为跨平台实现，在 Linux / macOS 上可直接运行。个别功能有平台差异：

| 功能 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| 截图识别 / 翻译 / 历史 | ✅ | ✅ | ✅ |
| PDF 整档识别 / 表格 / 贴图 / 导出 | ✅ | ✅ | ✅ |
| 全局热键 | ✅ | ⚠️ 需 sudo 运行，失败时自动降级为按钮/托盘触发 | ⚠️ 需在 系统设置→隐私与安全→辅助功能 授权 |
| 长截图自动滚动 | ✅ | ❌ 启动时提示（依赖 Win32 滚轮注入） | ❌ 同左 |
| GPU 加速 | CUDA / DirectML | CUDA（onnxruntime-gpu） | CPU（可装 onnxruntime-coreml） |

在目标平台上运行自检脚本即可确认：

```bash
python tests/platform_check.py
```

热键或长截图不可用时程序不会崩溃：GUI 按钮、托盘菜单均照常工作。

## 快速开始

```bash
pip install -r requirements.txt
python entry.py
```

## 打包为单文件 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name SnapOCR --collect-all rapidocr entry.py
```

生成 `dist/SnapOCR.exe`。

## 长截图说明

框选区域后会出现悬浮控制条：点「开始」自动注入滚轮下滚并逐帧拼接，滚到页面底部会自动结束（也可随时点「停止」），完成后弹出预览窗口，可保存 PNG、复制图片，或点「识别并复制」「识别并翻译」直接处理整页文字。相关参数（滚轮格数、滚动间隔、帧数/高度上限）见 `app/config.py` 的 `LONGSHOT_*` 常量。

已知限制：

- 固定页眉/悬浮元素会在每帧重复出现，导致拼接图中重复或错位
- 页面中有动画/视频的区域可能拼接不齐
- 仅支持主显示器；采集时会短暂接管鼠标滚轮

## 翻译说明

翻译使用免费公共接口，无需注册和 API Key：必应翻译为主（自动检测语言、无配额），MyMemory 自动兜底。目标语言默认中文简体，可在翻译窗口下拉切换（支持简繁中文、英、日、韩、法、德、西、俄、越、泰）。**注意：翻译功能需要联网**，OCR 识别本身仍然完全离线。

## 隐私

OCR 识别不联网、不上传，全部在本机完成。仅当使用翻译功能时，文本会发送到必应翻译 / MyMemory 公共接口。
